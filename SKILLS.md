# Skills and Technologies Used in the art-portal Project

## Technologies
1. **HTML/CSS**: Fundamental technologies for creating web pages.
2. **JavaScript**: Programming language for client-side operations.
3. **Node.js**: JavaScript runtime that allows server-side scripting.
4. **Express.js**: A web application framework for Node.js to build APIs.
5. **MongoDB**: NoSQL database used for data storage.
6. **Mongoose**: ODM (Object Data Modeling) library for MongoDB and Node.js.

## Frameworks
1. **React**: JavaScript library for building user interfaces, especially for single-page applications.
2. **Redux**: State management library for JavaScript apps.
3. **Bootstrap**: CSS framework for responsive web design.

## Other Skills
1. **Git/GitHub**: Version control system for tracking changes in code.
2. **RESTful API Design**: Principles and practices for designing APIs.
3. **Authentication and Authorization**: Implementation of secure login mechanisms.
4. **Agile Development**: Methodology used for iterative software development.

This project incorporates various technologies and skills aimed at creating a robust art portfolio platform that showcases projects and skills effectively. Each skill and technology contributes to the overall functionality and performance of the application.
